# WSTG, information gathering

## Objective

Map the application surface before testing anything: hosts, technologies,
endpoints, authentication mechanisms and data entry points.

## Checks

- WSTG-INFO-01: search engine discovery and reconnaissance.
- WSTG-INFO-02: fingerprint the web server and the framework.
- WSTG-INFO-05: review the content of the pages for comments, metadata and
  hidden fields.
- WSTG-INFO-06: identify the entry points, including parameters that accept a
  URL, a file name or a template.

## Output

A short list of technologies with versions, plus the entry points that deserve
an active test.
