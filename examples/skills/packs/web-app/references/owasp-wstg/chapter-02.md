# WSTG, configuration and deployment

## Objective

Find the weaknesses that come from the configuration rather than from the code.

## Checks

- WSTG-CONF-01: check the network infrastructure configuration exposed by the
  application (ports, services, administrative interfaces).
- WSTG-CONF-02: check the platform configuration files and the default accounts.
- WSTG-CONF-04: look for backup files, source archives and old directories.
- WSTG-CONF-07: verify the HTTP strict transport security and the cookie flags.

## Output

Each finding with its evidence and the impact on the engagement objective.
